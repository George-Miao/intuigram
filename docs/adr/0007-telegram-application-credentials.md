# Telegram application credential policy

Official Intuigram builds never contain or distribute a shared Telegram application ID and hash. Each installation uses credentials that its user creates and owns at `my.telegram.org`. Automation can provide the credentials through the documented environment variables. On the first run, missing values cause an explicit setup explanation and a hidden hash prompt. Intuigram then writes both values to a dedicated `credentials.toml`. It sets owner-only permissions on platforms that support them. Intuigram never overwrites this file automatically. General configuration stays separate. Diagnostics redact the hash. Release artifacts contain no application credentials. This policy adds setup work compared with a shared application identity. It does not publish a reusable secret. It does not put abuse and rate limits under one identity. It also does not incorrectly present a third-party distribution as an official Telegram application.
