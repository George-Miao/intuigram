# Workspace crates

Popgram is a virtual Cargo workspace whose packages all live under `crates/`. Popgram-specific packages use the `popgram-*` prefix, while genuinely reusable utilities use independent names. The initial crate seams are `popgram` for composition and the executable, `popgram-app` for application state and use-case interfaces, `popgram-tui` for terminal interaction and presentation, `popgram-telegram` for Telegram synchronization and protocol adaptation, `popgram-store` for durable local records, `popgram-media` for media transfer and cache policy, `popgram-config` for layered configuration, `compio-mtproto` for reusable MTProto transport and raw invocation, and `rich-clipboard` for platform clipboard content. `popgram-app` solely owns canonical application state and its transitions. The TUI submits typed user intents and renders read-only view data; Telegram, storage, and media adapters submit typed events. Ratatui widgets, Telegram TL values, database rows, and other adapter-specific types never cross the `popgram-app` interface. Dependencies point toward `popgram-app`; the executable composes concrete adapters, and adapter crates do not depend on each other. This creates independent test surfaces and reusable modules at the cost of more packages and explicit interfaces. New crates require a demonstrated seam and meaningful hidden behavior rather than merely grouping related types.
