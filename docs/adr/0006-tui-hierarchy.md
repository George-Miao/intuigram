# TUI hierarchy

Intuigram navigation uses the Chat list → Active Chat → Active Message hierarchy. It does not cycle focus through each visible region. When a user enters a Chat, its Composer becomes active by default. Message targeting is an explicit temporary descent from the Composer. `Esc` moves up one level at a time. A user can switch Folders only at the Chat-list level. Bare `Left` and `Right` do this. The `Alt` combinations are compatibility aliases. This design keeps ordinary typing available. It also makes context-sensitive actions predictable without keyboard modes or Tab-based focus traversal.
